# Академия

Демо-платформа для коротких курсов по управлению, дипломатии и геополитике. Сайт работает как статические HTML/CSS/JavaScript-файлы без сборки. Вход и регистрация отключены; отметки уроков и результаты тестов сохраняются в браузере.

Опубликованная демо-версия: [akademiya-course-demo.vercel.app](https://akademiya-course-demo.vercel.app/).

## Локальный режим

Откройте `index.html` в браузере. Отметки уроков и результаты тестов сохраняются только в `localStorage` этого браузера.

Для локальной разработки запустите HTTP-сервер, например:

```sh
py -m http.server 8000
```

Откройте `http://localhost:8000`.

## Прогресс

Сайт не запрашивает email, пароль или аккаунт и не синхронизирует данные с облаком. Supabase-файлы и таблица оставлены, но текущая версия сайта их не загружает и не использует.

Изменённый `supabase-config.js` является частью статического сайта. Для публикации в Vercel отправьте коммит в подключённый GitHub-репозиторий либо разверните репозиторий способом, которым обычно обновляете сайт.

## Проверки

Требуется Node.js. Запуск тестов:

```sh
node --test tests/*.test.cjs
```

Проверки покрывают курсы, тесты и локальный прогресс. Интеграция Supabase сохранена в репозитории, но отключена в опубликованной версии.
