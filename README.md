# Академия

Демо-платформа для коротких курсов по управлению, дипломатии и геополитике. Сайт работает без сборки и сторонних зависимостей.

## Запуск

Откройте `index.html` в браузере. Отметки уроков и результаты тестов сохраняются в `localStorage` этого браузера.

## Проверки

Требуется Node.js. Запуск тестов:

```sh
node --test tests/*.test.cjs
```
